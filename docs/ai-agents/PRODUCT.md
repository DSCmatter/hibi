# Product direction

Hibi helps people write notes and documentation in local files and nested folders. Writing should be ready as soon as the app opens. Markdown supports visual, source, and side-by-side editing; other formats offer the views they can support. A workspace can also become a portable documentation site.

## Design priorities

- Keep writing central and secondary controls quiet.
- Share navigation between settings, workspaces, and exported documentation.
- Preserve files and unsaved edits through every view change.
- Use short, subtle motion to explain changes without repeatedly rewrapping text.
- Keep keyboard navigation, labeled controls, rebindable shortcuts, and reduced-motion options. Honor the user's focus-indicator preference.

Use VS Code's file navigation and Codex's sidebar-aware window layout as references. Avoid decorative panels, unnecessary borders, large default gaps, and flickering settings.
