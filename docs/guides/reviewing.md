# Review a document

Enable **Review** in **Settings → Addons**, then choose **Review document** from the toolbar or command palette. The sidebar checks Markdown and plain text for repeated words and a small set of common English typos.

Select a suggestion to highlight it. Click its check button to apply the change, or use undo to restore the previous text. If a suggestion needs source view, switch views and check it again. Editing the document refreshes the suggestions.

Checks run locally while the sidebar is open. Review is not a complete spelling or grammar checker.
