# Word count

Turn on **Word count** in **Settings → Addons** to see word and character totals in the status bar. Counts follow the current document, including unsaved edits, pasted text, and undo. The plugin is off by default.

Markdown counts use the document's readable text in every view, leaving out formatting characters and frontmatter properties. Other formats count their source text.

Characters include spaces and line breaks. Joined emoji and letters with combining accents count as one character. Hibi uses language-aware word boundaries for word counts.

Counting happens on your computer. The plugin does not save or upload document text.
