# Review

Find repeated words and a small set of common English typos in Markdown and plain text. Enable Review in **Settings → Addons**, then choose **Review document** from the toolbar or command palette.

Select a suggestion to highlight its text. Use the check button to apply it; undo restores the previous text. Suggestions are refreshed after you edit. Code, links' destinations, properties, and text that cannot be mapped exactly are excluded. Some rich-text ranges require source view.

Checks run locally while the Review sidebar is open. No document content is sent to a server. This is a lightweight proofreading aid, not a complete spelling or grammar checker.
