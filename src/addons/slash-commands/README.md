# Slash commands

Type `/` at the start of a paragraph in normal view or a line in Markdown source to choose a block. This plugin is on by default.

Type a name or keyword to filter the menu. Use the arrow keys, then Enter or Tab, or click an item. Escape or a click outside closes the menu and keeps what you typed.

The menu includes text, headings 1–3, bullet and numbered lists, checklists, quotes, code blocks, dividers, and tables. Other enabled plugins can add commands, such as Frontmatter's note properties. Block changes support Undo.

The menu stays closed inside code, frontmatter, URLs, and paths. With Vim enabled, `/` searches in normal mode and opens slash commands in insert mode.
